# Shop photos

Drop the real photos of the shop in **this folder**, using these exact
filenames. Any file that isn't here yet is simply skipped — the gallery
shows whatever exists, and the whole "The shop." section stays hidden
until at least one photo is added. No code changes needed.

| Filename | What it should show |
|----------|---------------------|
| `exterior-1.jpg` | **Most important** — the storefront with the signage (shown large) |
| `exterior-2.jpg` | Another outside angle / the street |
| `counter-1.jpg`  | The parts counter |
| `interior-1.jpg` | Stock shelves — filters, valves, electrics |
| `interior-2.jpg` | More stock / inside the shop |
| `workshop-1.jpg` | The workshop floor |
| `workshop-2.jpg` | A repair bay, or a truck being worked on |
| `workshop-3.jpg` | Someone actually working — hands on a part |

**Tips**
- `.jpg` only, and keep the names lowercase exactly as above.
- Resize to about **1600px wide** before uploading and keep each file
  under ~500KB, so the site stays fast on mobile data.
- Landscape (horizontal) photos work best — they're cropped to 4:3.
- Photos with people working in them convert better than empty rooms.

**How to upload via GitHub (no coding):**
1. Open the repo → navigate into `public/photos/`
2. Click **Add file → Upload files**
3. Drag the photos in, then click **Commit changes**
4. Vercel redeploys automatically; the photos appear in a minute or two.
